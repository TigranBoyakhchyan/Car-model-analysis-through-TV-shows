# Car Model Analysis Through TV Shows

## Project Overview

This project analyzes the frequency of car models appearing in TV shows using web scraping techniques. The data was collected from the Internet Movie Cars Database (IMCDb.org) and processed to identify the most common car models across multiple TV series and determine in which shows they appear most frequently.

The project demonstrates the use of **Python, Selenium, and data analysis tools** to automate data collection, process the scraped information, and extract meaningful insights.

## Main Steps

* Web scraping car model data from IMCDb
* Automating navigation across TV show pages
* Collecting and aggregating car appearance data
* Identifying the most frequently appearing car models
* Analyzing the TV series where these cars appear most often
* Exporting results as CSV files for further analysis
